# Firebase AI Logic — MyCar+ V6.14

A análise inteligente usa Firebase AI Logic, App Check e o veículo selecionado na tela inicial. Configure `FIREBASE_CONFIG`, `MYCAR_RECAPTCHA_SITE_KEY` e, opcionalmente, `MYCAR_AI_MODEL`. Os indicadores são calculados localmente; a IA interpreta os dados e não deve inventar valores ou diagnósticos mecânicos.
