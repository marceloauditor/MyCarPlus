# MyCarPlus V5.30 — Versão Master

## Consolidação
- Projeto completo reunido em um único pacote-fonte.
- Base funcional da V5.29 incorporada ao repositório completo.
- `google-services.json` incluído em `android/app/`.
- Arquivos complementares preservados, incluindo `validation.css` e `mycar-plus-identidade.png`.
- Pastas geradas e locais removidas do pacote: `.git`, `node_modules`, `.idea`, `build`, `.gradle` e `local.properties`.
- Arquivos de listagem de diretório e comparação removidos.
- Documentos avulsos de versões anteriores consolidados no histórico técnico.

## Versão
- Aplicação e metadados atualizados para 5.30.0.

## Procedimento recomendado
1. Faça backup do projeto atual.
2. Extraia este pacote em uma nova pasta.
3. Execute `npm.cmd install`.
4. Execute `npm.cmd run sync:android`.
5. Abra a pasta `android` no Android Studio e gere o APK.
