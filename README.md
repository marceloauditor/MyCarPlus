# MyCar+ V5.30

Aplicativo Web/PWA e Android para controle de consumo, despesas, manutenção e gestão veicular.

## Estrutura padronizada

- A raiz do repositório contém a versão Web publicada pelo GitHub Pages.
- `www/` permanece como fonte Web do Capacitor para o Android.
- Execute `npm.cmd run sync:web-root` para copiar `www/` para a raiz.
- Execute `npm.cmd run sync:android` para sincronizar a raiz e atualizar o projeto Android.

Endereço Web oficial: `https://marceloauditor.github.io/MyCarPlus/`
