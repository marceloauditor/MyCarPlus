# MyCar+ V5.35

Aplicativo Web/PWA e Android para controle de consumo de combustível, manutenção, despesas administrativas, receitas, alertas e análises veiculares com IA.

## Regras centrais
O veículo selecionado na tela inicial controla indicadores, relatórios, gráficos, alertas, histórico técnico e MyCar+ Intelligence. Veículos inativos permanecem disponíveis para consulta histórica, sem operações ativas.

## Desenvolvimento
```powershell
npm.cmd install
npm.cmd run sync:web
npm.cmd run sync:android
```
