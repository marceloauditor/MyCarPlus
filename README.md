# MyCar+

Aplicativo Web/PWA e Android para controle de combustível, manutenção, despesas administrativas, receitas, alertas, relatórios e gráficos do veículo.

Versões: APP 6.14 · npm 6.14.0 · Android 614 / 6.14.0 · cache `mycar-plus-v6-14`.

## V6.14 — versão final de encerramento

- A tendência de consumo passa a ser apresentada como **Eficiência**, deixando claro que menor km/L representa piora.
- Tendências exibem Eficiência, Custo por km e Custo mensal.
- A tendência de Custo mensal permanece calculada no motor central, comparando duas janelas consecutivas de igual duração.
- Receitas na Composição dos Grupos são apresentadas entre parênteses, mantendo a dedução no Custo líquido.
- No celular, os valores dos grupos e o Custo líquido ficam alinhados à direita de forma uniforme.
- Validações de indicadores, centralização, gravação, sincronização e coesão permanecem obrigatórias.
