# MyCar+

Aplicativo Web/PWA e Android para controle de combustível, manutenção, despesas administrativas, receitas, alertas, relatórios e gráficos do veículo.

Versões: APP 6.12 · npm 6.12.0 · Android 612 / 6.12.0 · cache `mycar-plus-v6-12`.

## V6.12

- Painel local renderizado antes da ocultação do splash, eliminando o intervalo de tela preta.
- Relatório Executivo, Análise Inteligente e Gráficos com padrão da primeira movimentação do veículo até a data atual.
- Firebase e sincronização continuam em segundo plano após a primeira exibição.
