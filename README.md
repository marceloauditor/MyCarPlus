# MyCar+

Aplicativo Web/PWA e Android para controle de combustível, manutenção, despesas administrativas, receitas, alertas, relatórios e gráficos do veículo.

Versões: APP 6.13 · npm 6.13.0 · Android 613 / 6.13.0 · cache `mycar-plus-v6-13`.

## V6.13 — versão final de encerramento

- Tendências do Painel Inteligente passam a exibir Consumo, Custo por km e Custo mensal.
- A tendência de Custo mensal é calculada no motor central e compara duas janelas consecutivas de igual duração.
- Receitas na Composição dos Grupos são apresentadas entre parênteses, mantendo a natureza de dedução no Custo líquido.
- Validações de indicadores, centralização, gravação, sincronização e coesão permanecem obrigatórias no pacote de atualização.
